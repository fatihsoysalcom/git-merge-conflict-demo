# Git Merge Conflict Demo

This Bash script simulates a common Git merge conflict scenario. It initializes a Git repository, creates two feature branches (`feature-a` and `feature-b`) from the same point on `main`, and introduces conflicting changes to the same file (`README.md`) in both branches. The script then demonstrates how merging these branches into `main` leads to a merge conflict, showing the conflicted file's state and providing instructions on how to resolve it.

## Language

`bash`

## How to Run

1. Save the code as `run_conflict_demo.sh`.
2. Make it executable: `chmod +x run_conflict_demo.sh`.
3. Run it: `./run_conflict_demo.sh`.
